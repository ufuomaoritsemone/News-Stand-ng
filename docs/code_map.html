📱 News Stand NG (.NET MAUI) Architecture & Screen Map

Cross-platform client (Android, Windows, iOS) built with Clean MVVM, On-Device 14-Day SQLite Cache (WAL), Autonomous Widget Sync, Sonic Audio Feedback, and Zero-Jitter Scroll Stabilization.

NewsPersistenceService.cs 14-Day SQLite Store

On-device local SQLite store (CachedStoryEntity) operating in WAL mode (PRAGMA journal_mode=WAL;). Delivers instant 0ms app start-up, a 14-day rolling story cache with automatic non-bookmarked story eviction, and protects user bookmarks and read history from being purged.

Associated Code Services/NewsPersistenceService.cs Models/CachedStoryEntity.cs PruneOldStoriesAsync(14 Days)
NewsWidgetService.cs & Provider Enlarged Home Widget

Android Home Screen widget featuring +20% larger typography (16sp masthead, 17sp headline, 12sp category badges) and 77dp rounded article thumbnails. Utilizes WidgetImageHelper.cs with power-of-two downsampling to strictly respect the Android 1MB Binder transaction limit.

Associated Code Platforms/Android/NewsWidgetService.cs Platforms/Android/WidgetImageHelper.cs NotifyAppWidgetDataChanged()
BackgroundSyncService.cs Autonomous Doze Sync

Autonomous background synchronization engine powered by AlarmManager.SetAndAllowWhileIdle. Enforces WorkManager-grade network checks and low-battery deferrals. Governed by the user opt-out toggle NotificationPreferences.BackgroundUpdatesEnabled to preserve battery life.

Associated Code Platforms/Android/BackgroundSyncService.cs Platforms/Android/NewsSyncReceiver.cs BootCompletedReceiver.cs

🛡️ Enterprise Security, Hardening & Stress Testing Matrix

Architectural overview of the 8-Step API Hardening Roadmap and NBomber 6.6 distributed load testing suite.

Step 1: Secrets & Config Completed

Scrubbed all hardcoded credentials from committed repository files. Configured .NET Secret Manager (UserSecretsId) for local development and non-blocking startup audit logging in Program.cs.

Key Files NewsApi/Program.cs NewsApi/NewsApi.csproj
Step 2: Transport & Headers Completed

Enforced HTTPS redirection, HTTP Strict Transport Security (HSTS), and centralized security headers (CSP, X-Frame-Options: DENY, X-Content-Type-Options: nosniff, Permissions-Policy).

Key Files NewsApi/Program.cs (Security Headers Middleware)
Step 3: Auth & Fail-Closed Completed

Implemented fail-closed ApiKeyMiddleware (HTTP 503 in non-dev if secret key is missing; HTTP 401 on unauthorized write calls). Secured administrative endpoints while preserving public mobile telemetry.

Key Files Middleware/ApiKeyMiddleware.cs Services/FeedbackService.cs
Step 4: Validation & Uploads Completed

Model binding annotations ([Required], [Url], [StringLength]), 50MB request size limit on audio uploads, file extension whitelisting (.mp3, .wav, .m4a, .ogg, .aac), and path traversal protection.

Key Files Controllers/AudioController.cs Controllers/SourcesController.cs
Step 5: DTO Decoupling Completed

Decoupled API responses from EF Core database entities via dedicated strongly typed contracts (SourceDto, VideoChannelDto, SocialPostDto) and interface abstractions (IYouTubeFeedService, ISocialFeedService).

Key Files Models/ResponseDtos.cs Services/ISocialFeedService.cs
Step 6: Problem Details & Guards Completed

Standardized on RFC 9457 ProblemDetails (application/problem+json) for all API errors with correlation traceId. Added Response.HasStarted defensive checks to prevent mid-stream header mutation crashes.

Key Files Middleware/GlobalExceptionMiddleware.cs
Step 7: Rate Limiting & DoS Defense Completed

Frontline sliding-window rate limiter configured for 120 req/min per IP. Cluster health checks (/health, /healthz) are permanently exempted, and X-Bypass-Rate-Limit header enables hardware saturation load testing.

Key Files Extensions/ServiceCollectionExtensions.cs
Step 8: Cooperative Cancellation Completed

Propagated CancellationToken across controller actions, EF Core async queries (ToListAsync, SaveChangesAsync), and outbound RSS scraper HTTP calls, eliminating orphaned threads on client disconnects.

Key Files Controllers/SourcesController.cs Controllers/ArticlesController.cs

🚀 Running News Stand NG Locally & Testing

The system supports one-click startup via PowerShell, Batch script, Docker Compose, or individual .NET / Node CLI commands.

Method 1: PowerShell Startup (Recommended)

Launches NewsApi, AdminDashboard, and NewsScraperService in interactive console windows or background jobs. 

# 1. Run all backend services with interactive logs
.\run-services.ps1

# 2. Launch backend services + Modernist Web Application
.\run-services.ps1 -Web

# 3. Or run silently in background jobs
.\run-services.ps1 -Background

# 4. Stop all running services
.\run-services.ps1 -Stop

Method 2: Docker Compose (Microservices)

Runs PostgreSQL 16, NewsApi, AdminDashboard, Scraper, and TtsWorker with shared persistent audio-data volume. 

# Launch all microservices + PostgreSQL via script
.\run-services.ps1 -Docker

# Or run direct Docker Compose
docker-compose up -d --build

# View container logs
docker-compose logs -f

Method 3: NBomber Load & Stress Testing

Execute high-concurrency benchmarks and stress scenarios with detailed latency exports. 

# 1. Run baseline test against port 5000 (Docker)
dotnet run --project tests/NewsApi.StressTests

# 2. Target standalone NewsApi (Port 56193)
dotnet run --project tests/NewsApi.StressTests -- --url http://localhost:56193

# 3. Read spike test (300 RPS, bypassing rate limit)
dotnet run --project tests/NewsApi.StressTests -- --scenario feed --rate 300 --bypass-rate-limit
